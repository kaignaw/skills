# 江苏装饰清单定额套项

本技能封装的是 **江苏省 2024 清单计量口径 + 江苏省 2026 消耗量** 的装饰套项流程，以及一个已经核对过的项目样本。目标是让下一次套项不必从零查规则、猜层次，而是按同一套字段和判定逻辑直接产出可复核的成果。

## 先确认三件事

1. **地区与版本**：本技能只适用于江苏省 2024 清单、2026 消耗量。用户若说“江苏”“苏建价”“2026 定额”，默认就是本口径；若是其他省份或 2014 定额，先说明不适用，不要混用编码。
2. **任务类型**：是“查已有子目”，还是“新项目套项”，还是“只把已有表转成 xlsx”。三种走法不同，见下文。
3. **交付物**：默认交付五张工作表的 xlsx（清单定额套用、清单库、定额子目、DXF 原文、编制依据）。若用户只要清单、只要定额、或只要某个构件，按需裁剪，但仍保留编码—名称—单位—规则四要素。

数据版本：`1.2.0`，整理日期 `2026-10-24`。清单依据 GB/T 50854-2024（江苏省 2024 版清单计量标准，江苏自 2026-06-01 起执行）；定额依据《江苏省建筑与装饰工程消耗量（2026）》（苏建价〔2026〕76 号，自 2026-06-01 起施行）。

**数据边界**：本技能内置三层数据，必须分清用途。

1. **清单种子库**：`data/boq_2024_jiangsu.csv`，26 条本项目实际引用并核对过的清单项，可直接作为本项目成果的清单名称、单位和规则依据。
2. **清单全量索引**：`data/boq_2024_jiangsu_index.csv`，477 条 = GB/T 50854-2024 的 472 条 + 江苏〔2025〕第 12 号公告增补的 5 条。26 条标“已核对”，其余 446 条标“国标提取”，5 条标“江苏增补（已核对）”。全量索引用于查编码、查名称、查单位和查规则；国标提取文本可能受网页/PDF 换行和上标丢失影响，正式成果应结合项目特征复核，不能只看名称。
3. **定额数据**：59 条已核对种子库（`quota_2026_jiangsu_seed.csv`）+ 3115 条全量索引（`quota_2026_jiangsu_index.csv`）。索引带物理 PDF 页码；59 条标“已核对”，3056 条标“自动提取”。自动提取名称可能受合并表头、上下标换行、多栏压缩影响，**不是官方名称库**，正式成果必须按 `页码` 回查原文，或以 59 条种子库为准。

遇到未收录做法时，按 `references/sources.md` 的官方链接回查原文，不要编造编号。江苏增补的 5 条是：`010103003 建筑垃圾外运`、`011601016 按质论价`、`011601017 建筑工人实名制`、`011601018 特殊施工降效`、`011601019 协管`；国标没有这些编码，不能反过来写成国标项目。

## 工作模式

### A. 只查子目 / 查已有做法

先查内置数据，不要凭记忆报编码：

```bash
python3 scripts/lookup.py boq 屋面
python3 scripts/lookup.py boqindex 屋面
python3 scripts/lookup.py boqindex 011101001 --json
python3 scripts/lookup.py quota 保温
python3 scripts/lookup.py quota --chapter 第十二章 --unit m3
python3 scripts/lookup.py index 保温
python3 scripts/lookup.py index 干挂 --chapter 第十三章
python3 scripts/lookup.py mapping 干挂
```

`boq` 只查 26 条已核对清单种子库；`boqindex` 查 477 条全量清单索引；`quota` 只查 59 条已核对定额种子库；`index` 查 3115 条定额全量索引，并显示 `页码`。建议顺序是：清单先用 `boqindex` 找编码，再用 `boq` 或项目特征复核；定额先用 `index` 找候选编号，再用 `quota` 或按页码回查原文确认名称、单位和构造。不要把 `index` 里的“自动提取”名称直接抄进正式成果。`lookup.py` 输出 Markdown 表；`--json` 输出机器可读结果（含名称质量、数据来源、备注）。查不到时，明确告诉用户“内置数据没有”，并说明需要回查标准/消耗量原文或请用户提供对应章节，不要编一个“看起来像”的编号。

### B. 新项目套项（主流程）

1. **提取做法原文**
   - DXF 先运行 `scripts/extract_dxf.py`，默认只读图层 `图名、说明`，自动识别 1–4 栏并按栏内 Y 降序还原阅读顺序。
   - 文字/图纸说明直接整理为“分部 → 做法编号 → 层序”的树。
   - 原文残缺、编号跳号、同一层被拆成多个文字碎片时，保留原文并标注“待核对”，不要替设计补内容。

2. **拆层，不拆项**
   - 先把每一“层”识别出来：结构层、找坡层、保温层、找平层、防水层、结合层、面层、保护层、界面处理、骨架。
   - 再判断它属于哪个清单实体。清单按“实体/部位”列项，定额按“施工层/材料/厚度/做法”拆子目。一个清单项下通常有多个定额子目，这是正常现象，不要为了“一行一项”硬合并。
   - 结构层（现浇板等）只作为 GTJ 建模对照，通常不属于装饰清单范围；如果保留，明确标“结构专业，仅供建模对照”。

3. **逐层匹配清单**
   - 用 `lookup.py boqindex` 查 9 位清单编码；如果该编码在 26 条种子库中，再用 `lookup.py boq` 复核项目口径。项目特征必须写全设计参数：材料、厚度、强度等级、粘结/铺贴方式、防水层数、上翻高度、基层类型、部位。
   - 辅助层如果已被清单工作内容或定额子目包含（例如块料面层中的结合层、抹灰中的素水泥浆、保温清单中的界面剂），不要重复列清单；在备注里写“含在××内”。
   - 辅助层如果标准/定额明确要求单列（例如干挂石材的钢骨架、吊顶的吊筋、石材面防护剂），就单列清单或单列定额，按规则处理。

4. **逐层匹配定额**
   - 先用 `lookup.py index` 在全量索引中找“章-子目”候选，再用 `lookup.py quota` 或索引 `页码` 回查原文确认；注意定额单位常见 `10m²`、`10m`、`m³`、`t`，不要擅自改成 `m²`。
   - 厚度不同优先用“基本子目 + 每增减 5mm/0.5mm”调整；调整次数按实际厚度差计算，不能想当然只加一次。
   - 材料不同但工艺相同，才允许“就近子目 + 材料换算”，并在备注中写明换算依据；没有对应子目时写“无对应子目/待查”，不要造编号。

5. **写 20 列套用表**
   - 同一 `序号` 下，**第一行**填清单字段；后续定额行的清单字段留空，表示沿用上一行清单项。
   - 每一层至少要有：图纸条文、清单归属（或“含在××内”）、定额归属（或“无对应/待确认”）、套用说明。
   - `计量单位` 是清单单位，`定额计量单位` 是定额单位，两列不能混。
   - 备注里写清楚：为什么这样列、依据哪条标准/定额说明、做了什么换算、还有什么没确认。备注不是可选项，它是后续复核的入口。

6. **生成并校验 xlsx**

```bash
python3 scripts/validate_mapping.py work/清单定额套用.csv
python3 scripts/build_xlsx.py \
  --mapping work/清单定额套用.csv \
  --dxf work/dxf/dxf_text.csv \
  --notes work/编制依据.md \
  -o 成果/装饰工程清单与定额套用表.xlsx
```

`validate_mapping.py` 会检查编码格式、清单组连续性、组内名称/单位一致性；清单编码区分“在 26 条种子库”“只在 477 条全量索引中”“全量索引也没有”，定额编号区分“在 59 条种子库”“只在 3115 条索引中”“索引也没有”。它不能替代专业复核，但能挡住大部分“空单位、错行、断组”的低级错误。

### C. 只转格式 / 只补几张表

用 `scripts/build_xlsx.py`，可只给 `--mapping`；`--dxf`、`--notes` 可选。表头必须是标准 20 列（见 `references/workflow.md`），否则脚本按列序写入并给出警告。

## 关键判定规则（摘要）

完整规则、条文依据和边界情形见 `references/mapping_rules.md`。先记住这几条最容易错的：

- **屋面找平/保护层**：按 GB/T 50854-2024 条文 J.6.5，屋面找平层、保护层、刚性隔离层通常归 `010902004 屋面刚性层`；也可与咨询方统一为 `011101006 平面砂浆找平层`，但一张表只能选一个口径并注明。
- **屋面保温找坡**：保温材料形成的找坡层按 `011001001 保温隔热屋面`；陶粒找坡属于类推，必须在备注中写明“按 J.6.5 类推，待确认”。
- **楼地面找平**：楼面找平层用 `011101006`；细石混凝土找平/找坡用 `011101007`；块料面层自带的粘结层不另列清单。
- **防水**：屋面卷材 `010902001`；楼地面涂膜 `010904002`；上翻 ≤300mm 并入楼地面，不另列。
- **保温**：屋面 `011001001`，墙面 `011001003`。墙面聚苯板常用 `10-61`（m³，面积×厚度）；若当地要求按面积口径，需回查 `10-42`（10m²），两者不能混用。
- **干挂石材**：清单 `011203001`；定额 `13-136` 只含面板安装，钢骨架另套 `13-194` 制作、`13-195` 安装（t）。
- **吊顶**：清单 `011302001`；定额要拆“龙骨 + 吊筋 + 面层”，如铝合金条板 `14-31 + 14-35/36 + 14-64`，矿棉板 `14-15 + 14-37/38 + 14-68`。
- **金属面油漆**：清单 `011402003`；2026 消耗量没有“耐酸漆/满刮腻子”的完全对应子目，只能就近套调和漆子目并做材料换算，必须显式标注“无专项子目”。
- **单位换算**：`10m²` 定额量 = 面积 ÷ 10；`10m` 定额量 = 长度 ÷ 10；保温板 m³ 定额量 = 面积 × 厚度（m）；厚度调整按 5mm 步距计算次数。

## 输出字段

主表固定 20 列，顺序不要变，便于后续脚本和人工复算：

`序号 | 部位/分部 | 做法编号 | 做法名称 | GTJ构件/做法建议 | 做法层序 | 图纸做法条文 | 清单子项 | 清单编码 | 清单名称 | 项目特征描述 | 计量单位 | 工程量计算规则 | 清单工作内容 | 定额编号 | 定额子目名称 | 定额所属章节 | 定额计量单位 | 定额工作内容 | 套用说明/备注`

字段含义、续行规则和填写示例见 `references/workflow.md`。

## 质量红线

- 不编造清单编码、定额编号、子目名称、计量单位；查不到就写“待查/无对应子目”。
- 不把 `quota_2026_jiangsu_index.csv` 的“自动提取”名称直接当标准名称；正式成果用 59 条种子库，或按索引页码回查原文后再写。
- 不把 `boq_2024_jiangsu_index.csv` 的“国标提取”文本当成逐字官方原文；编码、名称、单位可用于查号，项目特征和计算规则要结合项目特征复核。江苏增补的 5 条不能标成国标项目。
- 不把“结构层”混进装饰清单当成普通装饰项；如需保留，标注“结构专业，仅供建模对照”。
- 不把辅助层重复列清单；也不把标准明确要求单列的项目（钢骨架、吊筋、防护剂等）漏掉。
- 不把清单单位直接套到定额单位上；定额量按定额单位换算。
- 不隐藏假设。所有“类推、换算、待确认、图纸残缺”都写进备注，并在交付说明中汇总。
- 交付前至少检查：每个做法层都有交代；每个清单组首行有编码；每个定额行有单位；xlsx 五张表都能打开。

## 已知待确认事项（来自样本项目）

这些不是“标准答案”，而是下一次遇到同类做法时需要优先向设计/咨询方确认的点：

1. **外墙2 第 3 条只有“3、墙面”**：DXF 原文残缺，不能猜。保留“待核对设计大样”，不要补编码。
2. **屋面陶粒找坡按保温列项**：`011001001 + 10-17` 是依据 J.6.5 的类推；若当地按“楼地面垫层”口径，需改 `010501002` 并调整定额。
3. **银粉保护剂按屋面刚性层**：`010902004 + 9-135` 是保护层口径，清单工作内容与涂料保护层有差异，项目特征要写“涂膜保护层”。
4. **金属面耐酸漆/满刮腻子/除锈**：2026 消耗量无完全专项子目；`15-130/131/133` 只是就近调和漆/防锈漆子目，不能假装完全对应。
5. **5-32 卵石灌 M2.5**：套 `12-18 碎石干铺灌浆` 需换算碎石/砂浆材料；焦渣垫层套 `4-93` 也需换算，均应在备注标明。
6. **墙面 EPS 保温 10-61 与 10-42**：`10-61` 是 m³ 口径，`10-42` 是 10m² 口径；种子库只收录 `10-61`，`10-42` 可在全量索引中查到，但必须按页码回查原文后才能用于成果。
7. **50mm 混凝土垫层用 12-31 + 12-34**：12-34 是每增减 5mm，50mm 与 40mm 相差 10mm，应调整两次。样本表用一行 12-34 表示时，要在工程量中乘 2；若拆成多行，就列两次，避免只算 5mm。
