# 江苏装饰套项规则与边界

本文按分部整理最容易出错的判断。条文依据来自 GB/T 50854-2024 和《江苏省建筑与装饰工程消耗量（2026）》；括号内“13章说明二.4”这类表述是原整理时记录的条文说明位置，正式成果中应回查原文并写全。

## 1. 通用原则

1. **清单按实体，定额按施工层**：清单是“做什么实体”，定额是“怎么做、用什么材料、多厚”。一个清单项下多定额行是常态。
2. **先判断“含不含”，再判断“列不列”**：清单工作内容或定额工作内容已经包含的辅助层，不重复列；标准明确要求单列的（钢骨架、吊筋、防护剂），不能漏。
3. **项目特征承载设计参数**：厚度、强度、配比、铺贴方式、防水层数、上翻高度、基层类型，都要写进项目特征，否则定额无法复原。
4. **定额单位不改造**：定额是 `10m²` 就按 `10m²` 计量，在备注写“面积÷10”；不要为了好看把定额单位改成 `m²`。
5. **不确定就标注**：类推、换算、图纸残缺、无专项子目，全部写进备注。一个诚实的“待确认”比一个看起来完整的错编码更有价值。

## 2. 屋面

### 2.1 保护层 / 找平层 / 刚性层

- 清单：`010902004 屋面刚性层`。
- 依据：GB/T 50854-2024 条文 J.6.5，屋面工程中的找平层、保护层及刚性隔离层按“屋面刚性层”列项。
- 定额：
  - 20mm 1:3 水泥砂浆找平，下部为填充材料：`12-29`（10m²）；下部为混凝土/硬基层：`12-28`。
  - 银粉保护剂：`9-135 铝基反光隔热涂料涂刷一遍`（10m²），材料按设计换算。
- 边界：
  - 涂料类保护层与“刚性层”工作内容不完全一致，项目特征写“刚性层作用：涂膜保护层”，并注明与咨询方确认。
  - 找平层也可按 `011101006 平面砂浆找平层` 列，但同一张表只能选一个口径；不要屋面套刚性层、楼面又套平面找平层却不说明。

### 2.2 卷材防水

- 清单：`010902001 屋面卷材防水`（m²）。
- 定额：平面 `9-41`、立面 `9-42`（10m²）；厚度 δ3mm 与子目取定一致。
- 上翻：女儿墙上翻 250mm ≤300mm，清单工程量并入屋面，不另列；定额平面/立面分开。
- 若施工方案为热熔满铺/条铺/空铺，按对应子目替换，不要仍用冷粘法。

### 2.3 保温 / 找坡

- 清单：`011001001 保温隔热屋面`（m²）。
- 定额：
  - 陶粒混凝土找坡：`10-17`（m³），工程量 = 面积 × 平均厚度。
  - 喷涂聚氨酯：`10-24`（40mm，10m²）+ `10-25`（每增减 5mm，10m²）。80mm = 40 + 8×5。
- 边界：
  - 陶粒找坡不是严格保温材料，按 J.6.5 类推列 `011001001`；若当地按 `010501002 楼地面垫层`，需改清单并调整定额，不能两张表混用。
  - 设计未注明抗裂砂浆/网格布时，不要擅自加 `10-62/10-64`；如规范要求，另列并说明。

## 3. 外墙

### 3.1 面砖外墙

- 面砖：清单 `011203003 块料墙、柱面`；定额 `13-73`（单块 ≤0.06m²，10m²）。规格不同按 `13-75/13-77/13-79` 选。
- 打底/找平：清单 `011201001 墙、柱面一般抹灰`；定额 `13-32`（轻质墙）或 `13-10`（混凝土外墙）/`13-26`（砖墙）。块料子目不含基层抹灰，必须另列。
- 保温：清单 `011001003 保温隔热墙面`；定额 `10-61`（m³，面积×厚度）。
- 界面剂：若在结构墙表面，`13-47`；若在保温板面，通常已含在保温/抹灰工作内容，不重复。
- 素水泥浆：13章说明二.13，混凝土墙/轻质墙抹灰已含刷一道 901 胶素水泥浆，不另计。

### 3.2 干挂石材外墙

- 清单：`011203001 石材墙、柱面`（m²）。
- 定额：`13-136` 挂钩式干挂石材·墙面·密缝（10m²）。
- 钢骨架：13章说明三.6/三.7，干挂石材子目不含钢骨架、预埋（后置）铁件；另套 `13-194` 制作、`13-195` 安装（t）。
- 腔内保温：`011001003 + 10-61`，工程量按实际铺设体积；注意粘结面积 20%、空气层 10mm 等设计参数写进项目特征。
- 若按“石材幕墙”设计与验收，清单应改 `011206002 构件式石材幕墙`，不要仍套墙柱面。

### 3.3 涂料外墙 / 水泥砂浆外墙

- 涂料：清单 `011404001 墙面喷刷涂料`；定额 `15-169` 外墙苯丙乳胶漆·抹灰面（10m²）。
- 2026 消耗量没有“无机建筑涂料”专项子目时，按 15 章说明九换算材料；不要编新子目。
- 抹灰：清单 `011201001`；定额 `13-10`（混凝土外墙）或 `13-26`（砖墙）；总厚 18mm 与子目 20mm 不同，按 13章说明二.1 调整砂浆用量。
- 保温：`011001003 + 10-61`；界面剂 `13-47`。

### 3.4 玻璃幕墙

- 清单：`011206001 构件式玻璃幕墙`（m²，按框外围，扣开启扇）。
- 定额：`13-154` 铝合金玻璃幕墙·明框（10m²）；隐框/半隐框按设计改 `13-152/13-153`。
- 钢骨架：13章说明三.6，全钢骨架时执行相应铝合金幕墙子目、人工×0.6，钢骨架另按 `13-194/13-195`。
- 预埋/后置铁件：幕墙子目不含，按说明三.7 另计。

## 4. 楼地面

### 4.1 石材/块料面层

- 石材：清单 `011102001 石材楼地面`；定额 `12-74` 干硬性水泥砂浆（10m²），结合层约 30mm。
- 地砖：清单 `011102003 块料楼地面`；定额按粘结方式选 `12-112`（干硬性水泥砂浆）、`12-114`（水泥砂浆）、`12-115`（干粉型粘结剂）。
- 结合层、素水泥浆：通常已含在面层子目，不另列清单；若定额工作内容确实不含，再单列。
- 石材磨边：12章说明八，石材磨边未包括，设计磨边另套 `16-33~16-35`。

### 4.2 找平层 / 垫层

- 楼面水泥砂浆找平：清单 `011101006 平面砂浆找平层`；定额 `12-28`（硬基层）或 `12-29`（填充材料上）。
- 细石混凝土找平/找坡：清单 `011101007`；定额 `12-31`（40mm）+ `12-34`（每增减 5mm）。
  - 30mm = 40 − 2×5；35mm = 40 − 1×5；50mm = 40 + 2×5。
  - 同一增减子目可以在计价软件中把工程量乘以次数；若拆成多行，就列对应次数。
- 混凝土垫层：清单 `010501002 楼地面垫层`（m³）；定额 `12-21`（现浇不分格）。12章说明一：厚度 60~150mm 按垫层计；≤60mm 按找平层计。
- 灰土垫层：`010501002 + 12-1`（3:7，m³）。
- 素土夯实：2024 清单无独立项目，并入 `010501002` 项目特征；定额 `1-39`（10m²）。若有厚度分层回填，改 `1-42/1-44`（m³）。

### 4.3 防水

- 清单：`010904002 楼(地)面涂膜防水`（m²）。
- 定额：
  - 改性沥青涂料：`9-90`（2mm 平面）+ `9-92`（每增减 0.5mm 平面）。3mm = 2 + 2×0.5。
  - 聚氨酯：`9-102`（2.0mm 平面）+ `9-104`（每增减 0.5mm 平面）。1.5mm = 2.0 − 1×0.5。
- 上翻 ≤300mm：清单工程量并入楼地面，不另列；定额立面部分可另套 `9-91/9-93` 或 `9-103/9-105`，按展开面积。
- 找坡层：平均厚度计入；找坡引起的厚度差不能忽略。

### 4.4 焦渣 / 轻集料 / 卵石

- 焦渣垫层：第十二章无专项，按第四章 `4-93 炉渣垫层·水泥石灰拌和`（m³），配合比按设计换算；备注写明“跨章借用”。
- 轻集料混凝土：`12-31` 按细石混凝土子目换算为 CL7.5 轻集料混凝土；也可比选 `12-25 成品陶粒混凝土填充层`（m³），两口径需统一。
- 5-32 卵石灌 M2.5：2026 无“卵石灌浆”专项，就近 `12-18 碎石干铺灌浆`（m³），骨料换算为卵石、灌浆材料换算为 M2.5 混合砂浆；或者比照 `4-100 毛石·灌砂浆`，需与造价管理机构确认。

## 5. 踢脚线

- 块料踢脚：`011105003`；定额 `12-127` 同质地砖踢脚线（10m）。
- 石材踢脚：`011105002`；定额 `12-80` 石材块料面板·踢脚线（10m）。
- 水泥砂浆踢脚：`011105001`；定额 `12-48`（10m）。
- 12章说明四：踢脚线子目按高度 150mm 编制；设计 100mm 时，面层材料按比例调整，其他不变。定额量 = 长度 ÷ 10。
- 界面剂甩毛：无专项时按 `13-47` 刷界面剂，消耗量按设计调整；砖墙基层改 `13-48`。

## 6. 墙裙 / 内墙面

### 6.1 石材墙裙

- 清单：`011203001 石材墙、柱面`（m²）。
- 定额：`13-120` 石材块料面板·砂浆粘贴·墙面（10m²）；防护剂 `16-64`（10m²，按展开面积）。
- 打底抹灰：13章说明二.4，镶贴块料子目不含基层抹灰，另列 `011201001 + 13-11`。
- 13章说明二.13：混凝土墙抹灰已含 901 胶素水泥浆，不另计。

### 6.2 内墙抹灰 + 涂料

- 抹灰：`011201001`；定额 `13-11`（混凝土墙内墙），砖墙改 `13-9`，轻质条板改 `13-12`。
- 涂料：`011404001`；定额 `15-161` 内墙面乳胶漆二遍（10m²）。遍数不同按 `15-162` 调整；涂料品种不同按 15章说明九换算。
- 设计未注明遍数时，暂按二遍并在备注写“暂按”，不要默认成无限遍。

### 6.3 内墙瓷砖

- 清单：`011203003 块料墙、柱面`。
- 定额：`13-73`（单块 ≤0.06m²，10m²）；200×300=0.06m²，正好按“以内”。
- 打底：`011201001 + 13-11`；块料子目不含打底。
- 白水泥擦缝、素水泥浆通常含在面层子目，不另列。

## 7. 天棚

### 7.1 抹灰天棚

- 清单：`011301001 天棚抹灰`（m²，水平投影）。
- 定额：`14-102` 混凝土天棚水泥砂浆面·现浇（10m²）+ `14-101` 刷 901 胶素水泥浆（10m²）。
- 14章说明九：砂浆品种、厚度与子目不同按附录调整。
- 天棚涂料：清单 `011404002`；定额 `15-161`，15-161 注 1：柱、梁、天棚面刷乳胶漆人工×1.1。

### 7.2 吊顶

- 清单：`011302001 平面吊顶天棚`（m²，水平投影；扣窗帘盒，不扣≤0.3m²独立柱/孔洞）。
- 定额拆三块：龙骨 + 吊筋 + 面层。
  - 铝合金条板：`14-31` 龙骨（中型）+ `14-35` 吊筋 φ6 H=750 + `14-36` 高度每增减 100mm + `14-64` 面层开缝。
  - 矿棉板/岩棉板：`14-15` 装配式 T 型铝合金龙骨 600×600 + `14-37` 吊筋 φ8 + `14-38` 高度调整 + `14-68` 矿棉板面层。
- 14章说明三：吊筋、龙骨、面层分开计算；吊筋子目按膨胀螺栓连接楼板编制，设计为板底预留吊环时仍执行吊筋子目，预埋吊环不另计。
- 吊杆高度与 750mm 不同时，用 `14-36/14-38` 按 100mm 步距调整；不要漏。
- 面层规格/材质不同：按设计换算材料；条型矿棉板龙骨不符时按 14章说明一.4 换算。

## 8. 油漆、涂料

### 8.1 木材面

- 清单：`011401004 木材面油漆`（m²）。
- 定额：`15-4` 底油一遍、刮腻子、调和漆二遍·其他木材面（10m²）。
- 设计为局部刮腻子时，腻子用量按设计调整；木门/木窗/木扶手/木踢脚线分别改 `15-1/15-2/15-3/15-5`。
- 油漆颜色由室内设计确定；15章说明二：颜色与子目不符时人工、材料不调整。

### 8.2 金属面

- 清单：`011402003 金属面油漆`（m²）。
- 定额组合：`15-133` 红丹防锈漆第一遍 + `15-130` 调和漆第一遍 + `15-131` 调和漆第二遍（10m²）。
- 2026 消耗量**没有**“金属面耐酸漆”“金属面满刮腻子”专项子目：
  - 耐酸漆：暂按调和漆子目换算材料，遍数对应；备注“无专项子目，材料换算”。
  - 满刮腻子：15-152~15-156 只列抹灰面/夹板面/石膏板面/刮糙面/混凝土墙面，无金属面；建议并入油漆子目或按补充定额，必须确认。
- 除锈：清单 `011402005 金属构件除锈`（t）；2026 消耗量未单列除锈子目，除锈已含在油漆子目工作内容（15-130/15-133 的“除锈、清扫”）。若设计喷砂/抛丸，需补充定额或专项约定。
- 若按构件质量列项，金属面油漆清单可改 `011402004`（t），不要与 m² 混用。

## 9. 结构层

- 现浇混凝土楼板/屋面板：清单 `010502013 实心楼板`（m³）；定额 `5-22` 现浇混凝土实心楼板（预拌泵送，m³）。
- 结构层通常不属于装饰专业范围，列入主表时标“结构专业，仅供 GTJ 建模对照”，不要混进装饰清单合计。

## 11. 待确认事项的处理模板

备注建议统一写成：

```
【依据】……（标准/定额条文）
【换算】……（材料/厚度/单位）
【待确认】……（设计/咨询方需明确的事项）
```

示例：

```
【依据】GB/T 50854-2024 J.6.5，屋面找平层按屋面刚性层列项。
【换算】12-29 为20mm，设计20mm，不调整；下部为陶粒找坡，按“在填充材料上”。
【待确认】涂料类保护层与刚性层工作内容不完全对应，项目特征注明“涂膜保护层”，待咨询方确认。
```

不要把“待确认”写成“按常规”或“满足设计”，那等于没有交代。
