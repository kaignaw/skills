# 样本项目已知待确认事项

来自 `data/mapping_examples.csv` 对应的样本项目。这些**不是标准答案**，而是下次遇到同类做法时要优先向设计/咨询方确认的点；写成果时同样应写进备注。

1. **外墙2 第 3 条只有“3、墙面”**：DXF 原文残缺，不能猜。保留“待核对设计大样”，不要补编码。
2. **屋面陶粒找坡按保温列项**：`011001001 + 10-17` 依据 J.6.5 类推；若当地按“楼地面垫层”口径，需改 `010501002` 并调整定额，备注写明“类推，待确认”。
3. **银粉保护剂按屋面刚性层**：`010902004 + 9-135` 是保护层口径，清单工作内容与涂料保护层有差异，项目特征要写“涂膜保护层”。
4. **金属面耐酸漆/满刮腻子/除锈**：2026 消耗量无完全专项子目；`15-130/131/133` 只是就近调和漆/防锈漆子目，不能当作完全对应。
5. **5-32 卵石灌 M2.5**：套 `12-18 碎石干铺灌浆` 需换算碎石/砂浆材料；焦渣垫层套 `4-93` 也需换算，均应在备注标明。
6. **墙面 EPS 保温 `10-61` 与 `10-42`**：`10-61` 是 m³ 口径（面积×厚度），`10-42` 是 10m² 口径，两者不能混用；主表中两条均已核对，选用前仍需按 `页码` 确认口径与当地要求。
7. **50mm 混凝土垫层用 `12-31 + 12-34`**：`12-34` 是每增减 5mm，50mm 与 40mm 相差 10mm，应调整两次。样本表用一行表示时要在工程量中乘 2，或拆成两行，避免只算 5mm。

同类新增待确认项，追加到本文件，并在 `data/mapping_examples.csv` 对应行的 `套用说明 / 备注` 里同步写一句。
