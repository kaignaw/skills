# 版本、来源与数据范围

## 1. 清单依据

- 标准：**GB/T 50854-2024《房屋建筑与装饰工程工程量计算标准》**。
- 江苏落地口径：江苏省 2024 版清单计量标准（江苏省住房和城乡建设厅〔2025〕第 12 号公告），自 **2026-06-01** 起全省执行。
- 国家标准实施日期：**2025-09-01**。
- 本技能使用的内容：附录 A~R 的全部 9 位清单编码、项目名称、项目特征、计量单位、工程量计算规则、工作内容；江苏增补项另按省公告附件补充。
- 清单种子库：`data/boq_2024_jiangsu.csv`（26 条，本项目实际引用并核对的项目，可直接用于本项目成果，不是全量附录）。
- 清单全量索引：`data/boq_2024_jiangsu_index.csv`（477 条 = 国标 472 条 + 江苏增补 5 条；26 条标“已核对”，446 条标“国标提取”，5 条标“江苏增补（已核对）”）。
- 原文获取说明：住建部官方 PDF 为图片型、无文本层，直接 `pdftotext` 无法得到文字；整理时用公开 HTML 全文（`https://www.xuebim.cn/count/50854.html`）重建表格，用官方 PDF 的页面 OCR 和项目已有清单库交叉核对。正式成果引用时仍应以官方 PDF/正式出版文本为准。
- 住建部公告页（含官方 PDF 下载）：`https://www.mohurd.gov.cn/gongkai/zc/wjk/art/2024/art_c713a0ba3ee241de91d00ba70a031312.html`。
- 江苏落地公告（苏建价〔2025〕第 12 号，2025-12-19）：`https://jsszfhcxjst.jiangsu.gov.cn/art/2025/12/22/art_49384_11697289.html`；附件 1~4 下载：`https://jsszfhcxjst.jiangsu.gov.cn/module/download/downfile.jsp?classid=0&filename=376d22995e1948e18901f2d57475fc78.zip`。
- 江苏增补 5 条：`010103003 建筑垃圾外运`、`011601016 按质论价`、`011601017 建筑工人实名制`、`011601018 特殊施工降效`、`011601019 协管`；前 1 条来自附件 1，后 4 条来自附件 2。

## 2. 定额依据

- 名称：**《江苏省建筑与装饰工程消耗量（2026）》**。
- 文号：**苏建价〔2026〕76 号**。
- 发布：2026-05-19；施行：**2026-06-01**。
- 适用范围：江苏省行政区域内建筑与装饰工程计价参考。
- 替代关系：2014 版《江苏省建筑与装饰工程计价定额》及配套计价规定同时停止使用。
- 已核对种子库：`data/quota_2026_jiangsu_seed.csv`（59 条，本项目实际引用并逐条核对的子目，可直接用于成果）。
- 全量查询索引：`data/quota_2026_jiangsu_index.csv`（3115 条唯一子目，含物理 PDF 页码；其中 59 条“已核对”，3056 条“自动提取”）。索引用于查号、定位和扩展，不替代原文；正式名称和单位以种子库或按页码回查原文为准。
- 官方通知页：`http://jsszfhcxjst.jiangsu.gov.cn/art/2026/5/19/art_8639_11773294.html`。
- 官方 PDF 直链（2026-10-24 可下载，815 页，约 13.3 MB）：`http://jsszfhcxjst.jiangsu.gov.cn/module/download/downfile.jsp?classid=0&filename=30e05614aa6f432083ab0600ace227b4.pdf`。
- 整理时曾使用淮安市住建局镜像：`https://hazjj.huaian.gov.cn/upload/2026-06/4fed997b-2157-4eba-a344-9f87685b74d0.pdf`（2026-10-24 复查已 404，仅作来源记录）。
- 扩充子目时，请从上述官方 PDF 重新提取，不要根据本技能的记忆补编号。

## 3. 数据是怎么整理出来的

1. **DXF**：`工程做法明细.dxf` 为 AutoCAD 2004 ASCII DXF，GBK/ANSI_936 编码，文字在图层 `图名、说明`，共 206 条 TEXT。按图面三栏（X≈3k–16k / 22k / 39k）和 Y 降序还原为“室外装修—屋面/外墙”“室内装修—地面/楼面/踢脚/墙裙/内墙/天棚/吊顶/油漆”的做法树。
2. **清单**：从 GB/T 50854-2024 附录 A~R 提取全部 472 条清单编码、名称、特征、单位、规则、工作内容；再合并江苏〔2025〕第 12 号公告增补的 5 条，形成 477 条全量索引。项目实际引用的 26 条单独保留为已核对种子库，避免把未核对条目混入成果。
3. **定额**：先用 `pdftotext -layout` 提取官方 815 页 PDF 文本，解析出 3115 个唯一子目（编号/名称/章/节/单位/工作内容/物理页码），写入 `quota_2026_jiangsu_index.csv`；再按本项目实际做法筛出 59 条，逐条核对名称、单位和构造，写入 `quota_2026_jiangsu_seed.csv`。解析脚本为 `scripts/build_quota_index.py`，处理了计量单位上标换行、节标题被表格数字行误识别、多行工作内容漏抓、多栏名称压缩等 PDF 文本问题。
4. **套用表**：按“清单组 + 多定额行”的方式生成 96 行，清单字段只在组首行填写，续行留空。所有“类推、换算、无对应、图纸残缺”均写入备注。
5. **校验**：用 `openpyxl` 检查无空缺单位/名称/编码格式，并生成五张工作表。

## 4. 全量索引的质量与复核

### 4.1 清单全量索引

`boq_2024_jiangsu_index.csv` 的定位是“清单查号索引”，字段为：

`序号 | 清单编码 | 清单名称 | 计量单位 | 附录 | 节 | 表号 | 项目特征 | 工程量计算规则 | 工作内容 | 名称质量 | 数据来源 | 江苏差异 | 备注`

- **26 条“已核对”**：与项目种子库名称、单位一致，可直接用于本项目成果。
- **446 条“国标提取”**：编码、名称、单位、附录/节、表号来自 GB/T 50854-2024 全文；项目特征、计算规则、工作内容由网页表格重建，可能受换行、上标丢失、跨页合并影响。正式使用前应结合项目特征复核，必要时按官方 PDF 回查。
- **5 条“江苏增补（已核对）”**：逐条取自江苏〔2025〕第 12 号公告附件，国标没有对应编码。
- **单位补正**：部分原文上标丢失（如 `m` 实为 `m³`/`m²`），已按同条“工程量计算规则”补正并在备注注明；`010506016~010506021` 单位为跨行合并单元格 `t`，网页文本未抓到，已按同表钢筋项目补正。
- **江苏差异**：R 类记录标注“高层/超高层施工措施费不单独列项；另增补 011601016~011601019”；5 条增补项标注“江苏增补；GB/T 50854-2024 无此清单编码”。

查询方式：

```bash
python3 scripts/lookup.py boqindex 屋面
python3 scripts/lookup.py boqindex 保温 --chapter 附录K
python3 scripts/lookup.py boqindex 011101001 --json
```

重建索引（需要 GB/T 50854-2024 全文 HTML 和 `beautifulsoup4`）：

```bash
python3 scripts/build_boq_index.py --html 50854.html
```

### 4.2 定额全量索引

`quota_2026_jiangsu_index.csv` 的定位是“查号索引”，不是“官方名称库”。它的字段为：

`序号 | 定额编号 | 定额子目名称 | 计量单位 | 章 | 节 | 页码 | 工作内容 | 名称质量 | 数据来源 | 备注`

使用边界：

- **59 条“已核对”**：与种子库完全一致，名称和单位可直接用于成果。
- **3056 条“自动提取”**：编号、章、节和页码来自官方 PDF；名称由文本分栏规则重建，可能受合并表头、上下标换行、多栏压缩影响。正式使用前必须按 `页码` 回查 PDF 原文。
- **100 条单位为“见表”**：原表单位在表头或附表中，索引未能稳定提取，备注会提示回查。
- **55 条工作内容为空**：多为五金、配件表或说明表，原表没有“工作内容”行；备注会提示。
- **316 条同名提示**：同一名称对应多个子目（不同厚度、规格、施工方式等），备注会提示“同名子目，需按页码/项目特征区分”。
- 索引页码是 **PDF 物理页码**，不是书刊印刷页码；用 PDF 阅读器跳到该页即可复核。

查询方式：

```bash
python3 scripts/lookup.py index 保温
python3 scripts/lookup.py index 干挂 --chapter 第十三章
python3 scripts/lookup.py index 10-61 --json
```

重建索引（需要官方 PDF 和 `pdftotext`）：

```bash
pdftotext -layout js2026.pdf js2026.txt
python3 scripts/build_quota_index.py --text js2026.txt
```

不要把索引里的自动提取名称直接写进投标/结算成果；也不要把索引称为“官方全量名称数据库”。

## 5. 数据范围与限制

- **清单种子库不是全量标准库**：26 条清单只是样本项目的引用子集；全量索引覆盖 477 条（国标 472 + 江苏增补 5），但其中 446 条为国标文本提取。新项目先用 `lookup.py boqindex` 查编码，再用 `boq` 或标准原文复核。
- **定额索引覆盖 3115 个编号，但名称质量分层**：索引可用于查号和定位，不等于 3115 条名称都已核对。正式成果仍以 59 条种子库或按页码回查原文为准。
- **不是官方软件数据库**：编码和名称来自标准文本，实际组价时仍应以当地计价软件（GTJ/GCCP/江苏清单库）中的版本为准，注意勘误和地方补充规定。
- **不是自动套项结果**：`mapping_examples.csv` 是人工整理的示例，包含待确认项；不能不经复核直接作为投标/结算依据。
- **价格不在本技能范围**：本技能只做清单列项和定额子目匹配，不含人工、材料、机械单价、费率、税金、措施费。需要组价时，另接当地信息价和费用定额。
- **地方差异**：江苏各市在安全文明施工、材料基价、补充定额上可能有差异；涉及具体项目时，以项目所在地造价管理机构的口径为准。

正式成果的“编制依据”建议写：

```
1.《房屋建筑与装饰工程工程量计算标准》GB/T 50854-2024；
2. 江苏省 2024 版清单计量标准（江苏省住建厅〔2025〕第 12 号公告）；
3.《江苏省建筑与装饰工程消耗量（2026）》（苏建价〔2026〕76 号）；
4. 项目设计图纸、工程做法明细及设计答疑；
5. 项目所在地现行材料信息价及费用定额。
```

不要把本技能的 `data/*.csv` 写成“官方全量名称数据库”。`boq_2024_jiangsu_index.csv` 覆盖 477 条清单，但其中 446 条为国标文本提取；`quota_2026_jiangsu_index.csv` 覆盖 3115 个定额编号，但其中 3056 条名称是自动提取。正式引用时以种子库或按原文回查为准。
