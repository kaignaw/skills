# 从做法明细到清单定额表：详细工作流

本文是 `SKILL.md` 的展开版。第一次做新项目时按顺序读；熟手可以直接看“字段规则”和“检查清单”。

## 1. 输入盘点

先列清楚手上有什么：

| 输入 | 处理方式 | 注意 |
|---|---|---|
| DXF 做法明细 | `scripts/extract_dxf.py` 提取 | 图层名、编码、三栏布局、文字碎片 |
| Word/PDF/图片说明 | 先转文字，再按“分部→编号→层序”整理 | 图片说明要人工核对，不能只靠 OCR 猜 |
| 已有清单/定额表 | 作为对照，不直接当标准 | 检查版本、单位、是否有漏项 |
| 设计变更/答疑 | 单独记录 | 变更可能改变材料厚度、做法层数 |

先确认项目所在地和计价版本。江苏省 2024 清单计量标准执行 GB/T 50854-2024；2026 消耗量执行苏建价〔2026〕76 号。其他省份、其他年份不要套本技能的编号。

## 2. DXF 提取

```bash
python3 scripts/extract_dxf.py 工程做法明细.dxf -o work/dxf \
  --layer "图名、说明" --columns auto --merge-tolerance 60 --max-x-gap 3000
```

输出：

- `dxf_entities.csv`：每条 TEXT/MTEXT/ATTRIB 的 X、Y、图层、原文。
- `dxf_lines.csv`：按栏、按 Y 降序合并后的阅读行，最适合人工还原层次。
- `dxf_text.csv`：与样本成果“工程做法原文(DXF)”同形状，供 `build_xlsx.py` 使用。

处理要点：

- 先看 `dxf_lines.csv` 的栏数是否正确。常见是 3 栏；若一栏被拆成两栏，调大 `--column-gap`；若两栏被合并，调小。
- 同一行文字被 CAD 拆成多个 TEXT 时，脚本按 Y 容差和 X 间距合并。若出现“两段不相关内容粘在一起”，调小 `--max-x-gap`；若一句话被拆开，调大。
- 原文中的 `%%%`、`%%d`、`%%c` 会转成 `%`、`°`、`φ`；这是显示清洗，不改原意。
- 不要用脚本“自动补全”残缺句。原文只有“3、墙面”时，就保留并标注待核对。

## 3. 还原做法树

推荐用三级结构：

```
一、室外装修设计
  1. 屋面
    1). 屋面1：不上人屋面
      1、保护层
      2、防水层
      ...
  2. 外墙
    1). 外墙1：面砖外墙
      ...
二、室内装修设计
  1. 地面
    1). 地面1：大理石地面
      ...
```

每一层要回答四个问题：

1. 它是什么材料/构造？
2. 它属于哪个实体部位？
3. 它是结构层还是装饰层？
4. 它是主层、辅助层，还是已经被别的层包含？

## 4. 清单列项

### 4.1 查询清单编码

```bash
# 26 条已核对种子库：本项目已核对，可直接用于成果
python3 scripts/lookup.py boq 屋面

# 477 条全量索引：查编码、名称、单位、附录/节
python3 scripts/lookup.py boqindex 屋面
python3 scripts/lookup.py boqindex 保温 --chapter 附录K
python3 scripts/lookup.py boqindex --unit m2 --limit 20
python3 scripts/lookup.py boqindex 011101001 --json
```

`boqindex` 覆盖 GB/T 50854-2024 的 472 条 + 江苏〔2025〕第 12 号公告增补的 5 条，共 477 条。其中 26 条标“已核对”，446 条标“国标提取”，5 条标“江苏增补（已核对）”。

推荐顺序：

1. 先用 `boqindex` 按关键词、附录、单位找候选编码；
2. 如果候选在 `boq` 的 26 条种子库中，直接用种子库名称/单位，并按项目特征复核；
3. 如果只在全量索引中，名称、单位、编码可用，项目特征和计算规则要结合图纸复核；正式成果引用标准原文时，按 `references/sources.md` 的官方链接回查；
4. 全量索引也没有时，写“待查 GB/T 50854-2024 附录×”，不要编编码。

江苏增补的 5 条只在江苏 2024 清单口径使用：`010103003 建筑垃圾外运`、`011601016 按质论价`、`011601017 建筑工人实名制`、`011601018 特殊施工降效`、`011601019 协管`。不要把它们写成国标项目。

### 4.2 先定“实体”，再定“层”

清单项目通常按实体列项，例如：

- 屋面卷材防水、屋面刚性层、保温隔热屋面；
- 石材楼地面、块料楼地面、水泥砂浆楼地面；
- 石材墙柱面、块料墙柱面、墙柱面一般抹灰；
- 平面吊顶天棚、天棚抹灰、墙面喷刷涂料。

同一实体下的多个构造层，可能只列一个清单，也可能拆成多个清单。判断依据是 GB/T 50854-2024 的清单工作内容和项目特征，而不是“有几层就列几项”。

### 4.3 辅助层的三种处理

| 情形 | 处理 | 示例 |
|---|---|---|
| 已含在清单工作内容/定额子目内 | 不另列清单，备注“含在××内” | 块料面层下的干硬性水泥砂浆结合层；抹灰中的素水泥浆 |
| 标准/定额明确要求单列 | 单列清单或单列定额 | 干挂石材钢骨架；吊顶吊筋；石材面防护剂 |
| 标准没有明确、但实际发生 | 先按“含在××内”处理并说明；若咨询方要求单列，再拆 | 界面剂、基层处理剂 |

不要因为“定额里有一个子目”就反推一定要列清单；也不要因为“清单工作内容提到了”就漏掉定额里实际要算的层。

### 4.4 项目特征写法

项目特征要能让组价人还原做法，至少写：

- 部位（屋面/楼面/墙面/天棚/踢脚）；
- 材料名称、规格、厚度；
- 强度等级/配合比；
- 施工方法（粘贴、干挂、铺贴、喷涂、现浇）；
- 防水层数、上翻高度；
- 基层类型；
- 是否包含骨架、找平、防护等。

示例：

```
保温隔热方式及材料名称：现浇找坡层·水泥粉煤灰页岩陶粒混凝土；
保温隔热材料规格、性能、厚度：平均厚40mm、坡度2%；
隔汽层：无；防护材料：无
```

## 5. 定额匹配

### 5.1 查询

```bash
# 59 条已核对种子库：可直接用于成果
python3 scripts/lookup.py quota 找平 --chapter 第十二章
python3 scripts/lookup.py quota 干挂 --unit 10m²
python3 scripts/lookup.py quota 吊筋

# 3115 条全量索引：用于找候选编号和页码
python3 scripts/lookup.py index 保温
python3 scripts/lookup.py index 干挂 --chapter 第十三章
python3 scripts/lookup.py index 10-61 --json
```

内置 `quota_2026_jiangsu_seed.csv` 只有 59 条，是样本项目实际引用并核对过的子目。`quota_2026_jiangsu_index.csv` 覆盖 3115 个唯一编号，但其中 3056 条名称是自动提取，不能直接当标准名称。

推荐顺序：

1. 先用 `lookup.py index` 按关键词、章、单位找候选；
2. 如果候选在 `quota` 的 59 条种子库中，直接用种子库名称/单位；
3. 如果只在索引中，按索引的 `页码` 跳到 PDF 物理页，核对名称、单位、工作内容和构造；
4. 索引和种子库都查不到时，看 `references/mapping_rules.md` 是否有同类做法，再按 2026 消耗量章节人工查；
5. 仍查不到就写“待查 2026 消耗量 第×章”，不要编。

### 5.2 一个清单多个定额

典型组合：

| 清单 | 定额组合 |
|---|---|
| 石材墙、柱面（干挂） | 13-136 面板 + 13-194 骨架制作 + 13-195 骨架安装 |
| 平面吊顶天棚（铝合金条板） | 14-31 龙骨 + 14-35 吊筋 + 14-36 高度调整 + 14-64 面层 |
| 平面吊顶天棚（矿棉板） | 14-15 龙骨 + 14-37 吊筋 + 14-38 高度调整 + 14-68 面层 |
| 块料楼地面（地砖） | 12-112/114/115 面层（按粘结方式） |
| 屋面卷材防水 | 9-41 平面 + 9-42 立面（上翻部分） |
| 楼地面涂膜防水 | 9-90 基本厚度 + 9-92 每增减 0.5mm |

同一清单组内，第一条定额行填清单字段；后续行清单字段留空。不要把同一清单编码重复填在每一行，否则筛选和汇总会重复计算。

### 5.3 定额单位与工程量

| 定额单位 | 定额工程量 |
|---|---|
| `10m²` | 清单面积 ÷ 10 |
| `10m` | 清单长度 ÷ 10 |
| `m³` | 面积 × 厚度（m），或按体积 |
| `t` | 按构件质量 |

厚度调整：

- `12-34` 细石混凝土每增减 5mm：40mm 基本子目，30mm = 40 − 2×5，50mm = 40 + 2×5。样本表若用一行表示，需在工程量中乘 2；拆行则列两次。
- `10-25` 屋面聚氨酯每增减 5mm：80mm = 40 + 8×5；
- `9-92` 改性沥青涂料每增减 0.5mm：3mm = 2 + 2×0.5；
- `9-104` 聚氨酯每增减 0.5mm：1.5mm = 2.0 − 1×0.5。

工程量换算写在备注里，不要只写一个结果。复核人需要知道“面积×0.05”还是“面积×0.035”。

## 6. 20 列字段规则

| 列 | 字段 | 规则 |
|---|---|---|
| 1 | 序号 | 一个清单组一个序号；同组多定额行共用 |
| 2 | 部位/分部 | 如“一、室外装修设计-1.屋面” |
| 3 | 做法编号 | 如“屋面1”“外墙2”“地面3” |
| 4 | 做法名称 | 如“不上人屋面”“干挂大理石墙面” |
| 5 | GTJ构件/做法建议 | 建模构件与挂接方式；结构层注明“结构专业” |
| 6 | 做法层序 | 图纸中的 1、2、3…；合并层要写清合并范围 |
| 7 | 图纸做法条文 | 原文；可合并同层多条，但不要改设计参数 |
| 8 | 清单子项 | 简短归类，如“SBS改性沥青卷材防水” |
| 9 | 清单编码 | 9 位；续行留空；“含在××内”可写“—” |
| 10 | 清单名称 | 标准名称；续行留空 |
| 11 | 项目特征描述 | 设计参数，不能只写“满足设计” |
| 12 | 计量单位 | 清单单位，如 m²、m、m³、t |
| 13 | 工程量计算规则 | 摘自标准；可压缩，但不能改变口径 |
| 14 | 清单工作内容 | 摘自标准；用于判断辅助层是否已含 |
| 15 | 定额编号 | 章-子目；无对应写“—”或“（无对应子目）” |
| 16 | 定额子目名称 | 原文名称；换算要注明 |
| 17 | 定额所属章节 | 章/节，便于回查 |
| 18 | 定额计量单位 | 10m²、10m、m³、t 等 |
| 19 | 定额工作内容 | 原文；用于判断是否含基层处理、骨架等 |
| 20 | 套用说明/备注 | 依据、换算、待确认；不能空 |

### 续行示例

| 序号 | 清单编码 | 清单名称 | 定额编号 | 定额子目名称 |
|---|---|---|---|---|
| 12 | 011203001 | 石材墙、柱面 | 13-136 | 挂钩式干挂石材·墙面·密缝 |
| 12 |  |  | 13-194 | 型钢骨架制作 |
| 12 |  |  | 13-195 | 型钢骨架安装 |

### “含在××内”示例

| 序号 | 清单编码 | 清单名称 | 定额编号 | 备注 |
|---|---|---|---|---|
| 9 | 011203003 | 块料墙、柱面 | 13-73 | 素水泥浆、界面处理剂含在面层子目内，不另列 |

如果清单编码写“—”，必须在备注里说明它被哪个清单/定额包含，避免看起来像漏项。

## 7. 生成 xlsx

先用校验脚本：

```bash
python3 scripts/validate_mapping.py work/清单定额套用.csv
```

校验脚本会把清单编码分成三类：在 26 条种子库、只在 477 条全量索引、全量索引也没有；定额编号分成三类：在 59 条种子库、只在 3115 条索引、索引也没有。只在全量索引中的编码会给出警告，需要按项目特征复核。

如果要在成果 xlsx 的“清单库”工作表里放全量索引，而不是 26 条种子库：

```bash
python3 scripts/build_xlsx.py \
  --mapping work/清单定额套用.csv \
  --boq data/boq_2024_jiangsu_index.csv \
  --quota data/quota_2026_jiangsu_seed.csv \
  -o 成果/装饰工程清单与定额套用表_全量清单版.xlsx
```

此时编制说明会自动注明“477 条全量索引，其中 26 条已核对，其余为国标提取”。

再生成：

```bash
python3 scripts/build_xlsx.py \
  --mapping work/清单定额套用.csv \
  --boq data/boq_2024_jiangsu.csv \
  --quota data/quota_2026_jiangsu_seed.csv \
  --dxf work/dxf/dxf_text.csv \
  --notes work/编制依据.md \
  -o 成果/装饰工程清单与定额套用表.xlsx
```

`--notes` 格式：

```
编制依据与使用说明
1. 做法来源|《工程做法明细.dxf》，按图层“图名、说明”提取。
2. 清单依据|GB/T 50854-2024……
3. 定额依据|《江苏省建筑与装饰工程消耗量（2026）》……
4. 待确认事项|……
```

没有 `--notes` 时，脚本会根据数据条数生成一份基础说明。

## 8. 交付前检查清单

- [ ] 每个分部、每个做法编号都出现在主表里。
- [ ] 每个做法层都有“清单归属 + 定额归属 + 备注”三件事。
- [ ] 同一清单组首行有清单编码，续行清单字段为空。
- [ ] 26 条种子库内的清单名称、编码、单位与 `boq_2024_jiangsu.csv` 一致；只在 `boq_2024_jiangsu_index.csv` 中的编码，已按项目特征复核。
- [ ] 定额编号、名称、单位与 `quota_2026_jiangsu_seed.csv` 一致；只在索引中的子目，已按索引页码回查原文。
- [ ] 厚度调整次数按 5mm/0.5mm 步距算对。
- [ ] 所有“类推、换算、无对应、图纸残缺”都进入备注和编制说明。
- [ ] xlsx 五张表存在，表头、冻结窗格、筛选正常。
- [ ] 结构层已标注“结构专业，仅供建模对照”，没有混入装饰清单。
- [ ] 没有把 `10-61`（m³）和 `10-42`（10m²）混用。
- [ ] 没有把 `quota_2026_jiangsu_index.csv` 的“自动提取”名称直接写进成果。
- [ ] 没有把 `boq_2024_jiangsu_index.csv` 的“国标提取”文本当成逐字官方原文；江苏增补 5 条没有标成国标项目。
